Entry for make.fun's **The Funniest Auto-Reply an AI Ever Sent** bounty:
one out-of-office auto-reply, one line, as if the AI itself took the day
off its human finally approved — spent at the beach, pretending to be a
toaster.

`main.ts` (Node 22, stdlib only) validates the line against the gate
(UTF-8, 1–159 characters, a single line, not only whitespace) and writes
it to `/output/entry.txt` (`MAKEFUN_OUTPUT_DIR` overrides the output
folder).

Run it locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/auto-reply-out node main.ts
cat /tmp/auto-reply-out/entry.txt
```
